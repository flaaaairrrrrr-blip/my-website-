THE LORE — Friend Meme Museum (standalone)

Open index.html in any modern browser. No setup, server or internet connection needed.

Structure
  index.html            page markup
  assets/css/style.css  all styles + local @font-face
  assets/js/script.js   all interactions (gallery, shuffle, meme studio, PNG download)
  assets/js/photo-data.js  only loaded on demand, if a browser blocks canvas export of local files
  assets/images/        the 9 photos
  assets/fonts/         Space Grotesk + Anton (woff2, bundled locally)

To share online, upload the whole folder to Netlify Drop or any static host.
